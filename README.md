# هم‌چین — دستیار هوشمند مدیرگروه

نسخهٔ پایلوت سامانهٔ تصمیم‌یار چینش گروه‌های درسی مهندسی کامپیوتر. موتور برنامه‌ریزی با OR-Tools CP-SAT، محدودیت‌های قطعی و سناریوهای تقاضای دانشجویان را هم‌زمان بررسی می‌کند.

## قابلیت‌های فعلی

- تعریف مستقل هر گروه با استاد، شماره گروه، ظرفیت و زمان‌های آزاد خودش
- تعیین تعداد جلسات هر گروه در هفته به‌جای اشتباه‌گرفتن جلسه با گروه
- پشتیبانی واقعی از کلاس‌های هر هفته، هفته‌های زوج و هفته‌های فرد
- ساخت گروه مازاد یک درس با استاد یکسان یا متفاوت
- تخصیص هم‌زمان ساعت و کلاس/آزمایشگاه
- جلوگیری قطعی از تداخل استاد، اتاق و گروه‌های موازی یک درس
- تعریف دسته‌های منع تداخل برای یک سال ورودی یا ترکیبی از چند ترم
- تعریف سناریوهای تقاضا برای ترم‌های عادی، دروس عقب‌افتاده و دانشجویان ترم‌بالاتر
- محاسبهٔ واقعی پوشش تداخل‌ها و پوشش ظرفیت
- تحلیل درخواست فارسی مدیرگروه برای اولویت یک درس یا ترم
- ارائهٔ علت ناممکن‌بودن برنامه و پیشنهاد افزایش گروه

## اجرای محلی در ویندوز

ساده‌ترین راه، دوبار کلیک روی فایل `بازکردن سایت هم‌چین.cmd` است. سرویس‌ها اجرا می‌شوند و سایت مستقیماً در Google Chrome باز می‌شود.

اجرای دستی بک‌اند:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

در ترمینال دوم، فرانت‌اند:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

سپس `http://localhost:3000` را باز کنید.

## آزمون

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest
```

```powershell
cd frontend
npm.cmd run typecheck
npm.cmd run build
```
