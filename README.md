# هم‌چین — دستیار هوشمند مدیرگروه

نسخهٔ پایلوت سامانهٔ تصمیم‌یار چینش گروه‌های درسی مهندسی کامپیوتر. موتور برنامه‌ریزی با OR-Tools CP-SAT، محدودیت‌های قطعی و سناریوهای تقاضای دانشجویان را هم‌زمان بررسی می‌کند.

## قابلیت‌های فعلی

- تعریف مستقل هر گروه با استاد، شماره گروه، ظرفیت و زمان‌های آزاد خودش
- تعیین تعداد جلسات هر گروه در هفته به‌جای اشتباه‌گرفتن جلسه با گروه
- پشتیبانی واقعی از کلاس‌های هر هفته، هفته‌های زوج و هفته‌های فرد
- ساخت گروه مازاد یک درس با استاد یکسان یا متفاوت
- تخصیص هم‌زمان ساعت و کلاس/آزمایشگاه
- جلوگیری قطعی از تداخل استاد، اتاق و گروه‌های موازی یک درس
- تعریف دسته‌های منع تداخل برای یک سال ورودی یا ترکیبی از چند ترم
- تعریف سناریوهای تقاضا برای ترم‌های عادی، دروس عقب‌افتاده و دانشجویان ترم‌بالاتر
- محاسبهٔ واقعی پوشش تداخل‌ها و پوشش ظرفیت
- تحلیل درخواست فارسی مدیرگروه برای اولویت یک درس یا ترم
- ارائهٔ علت ناممکن‌بودن برنامه و پیشنهاد افزایش گروه
- ساخت یک برنامه سراسری و ارائه ۸ نمای ترمی به‌همراه نمای کامل
- فهم ساخت‌یافته درخواست فارسی با Gemini و بازگشت امن به تحلیل داخلی
- ذخیره ماندگار نسخه‌ها، تقاضا و بازخورد در Neon Postgres
- پیش‌بینی تقاضا با CatBoost و یادگیری سلیقه مدیرگروه با CatBoost Ranker

## فعال‌سازی سرویس‌های رایگان هوشمند

در تنظیمات Environment Variables پروژه بک‌اند در Vercel این مقادیر را وارد کنید:

```text
DATABASE_URL=آدرس اتصال pooled دیتابیس Neon با sslmode=require
GEMINI_API_KEY=کلید رایگان Google AI Studio
GEMINI_MODEL=gemini-2.5-flash-lite
ML_TARGET_TERM=1405-1
```

اگر Gemini یا Neon تنظیم نشده باشند، برنامه از کار نمی‌افتد و به‌ترتیب از تحلیل داخلی و SQLite محلی استفاده می‌کند. وضعیت واقعی هر پنج موتور در خود پنل سایت نمایش داده می‌شود.

برای آموزش CatBoost، ابتدا داده‌های تاریخی را از مسیر `POST /api/demand/history` وارد کنید و سپس worker سبک‌نشده را محلی یا در یک کار زمان‌بندی‌شده رایگان اجرا کنید:

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install -r requirements-ml.txt
$env:DATABASE_URL="آدرس Neon"
.\.venv\Scripts\python.exe -m ml_worker.train --target-term 1405-1
```

CatBoost عمداً داخل تابع Vercel نصب نمی‌شود، چون همراه OR-Tools از محدودیت حجم تابع عبور می‌کند. worker فقط مدل را آموزش می‌دهد و خروجی کم‌حجم را در Neon ذخیره می‌کند؛ API اصلی آن خروجی را در چینش CP-SAT به کار می‌برد.

## اجرای محلی در ویندوز

ساده‌ترین راه، دوبار کلیک روی فایل `بازکردن سایت هم‌چین.cmd` است. سرویس‌ها اجرا می‌شوند و سایت مستقیماً در Google Chrome باز می‌شود.

اجرای دستی بک‌اند:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

در ترمینال دوم، فرانت‌اند:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

سپس `http://localhost:3000` را باز کنید.
